# Nexus

A professional, enterprise-grade Infrastructure Monitoring and Observability SaaS platform. Built with Next.js 15, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Real-time Observability** - Full-stack metrics and trace data ingestion.
- **Automated Alerts** - Intelligent baseline engine to prevent alert fatigue.
- **Continuous Optimization** - Weekly architectural reviews and bottleneck isolation.
- **Enterprise-Grade** - SOC2 Type II certified with 99.99% uptime SLA.
- **Modern Stack** - Next.js 15, React 19, and Tailwind CSS.

## 🛠️ Installation

1. Install dependencies:
  ```bash
  npm install
  ```

2. Start the development server:
  ```bash
  npm run dev
  ```
3. Open [http://localhost:4028](http://localhost:4028) with your browser to see the result.

## 📁 Project Structure

```
nextjs/

├── src/
```

## 🎨 Styling

This project uses Tailwind CSS for styling with a custom design system:
- **Neutral Palette**: Slate-based backgrounds and surfaces.
- **Indigo Accent**: Modern primary color for key interactions.
- **Accessibility**: WCAG AA compliant text contrast.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
